# 天猫 SKU 减钱速查

本目录是独立网页工具，保留本地运行版的匹配算法和最新页面功能。它不改变仓库中既有网站和采集器，也没有自动部署配置。

## 运行

需要 Node.js 22.13.0 或更高版本，无需安装第三方 Node 依赖。

```sh
cd tools/tmall-sku-price-check
npm test
npm run check
npm start
```

浏览器打开终端打印的本地地址。也可将 `public/` 交给静态网站服务；发布前应配置符合自身需要的访问权限。

## 使用

1. 点击“更新聚水潭资料”，导入商品资料 Excel、CSV、TSV 或粘贴表格，核对“商品编码”“卖价”“成本价”列后确认。
2. 粘贴天猫后台的 SKU 名称、价格和商家编码。每个 SKU 一行；同一商家编码的不同 SKU 会分别保留。
3. 结果按“天猫 SKU 名称、减钱、商家编码、天猫价格、聚水潭成本、聚水潭卖价、聚水潭毛利”显示。
4. “复制名称和减钱”一次复制两列，名称和金额逐行对齐；另保留整列金额、完整结果和每行金额悬浮复制。
5. 粘贴区“一键清空”只清除输入和本次结果，不清除商品资料。

当前资料保存在访问者浏览器中，可导出价格备份。公开源码默认没有商品资料；格式示例全部使用虚构的 `DEMO-SKU-*` 编码，不对应真实商品。真实资料、原始 Excel、单文件运行包和本机数据不属于本目录。

## 算法

- 减钱 = 天猫 SKU 价格 − 聚水潭卖价。参与减法的价格以整数分处理，显示两位小数；保留真实零值和负数。
- 聚水潭毛利 =（聚水潭卖价 − 聚水潭成本）÷ 聚水潭卖价，按两位百分比显示。成本保留原始精度，不先四舍五入到两位。缺成本、缺卖价或卖价为零时显示“—”及原因。
- 编码按首尾空白清理、去除内部换行、NFKC 规范化及大小写不敏感进行精确匹配，不做模糊匹配。
- 天猫 SKU 名称来自粘贴内容，不把聚水潭规格伪装为天猫名称；同名、重复编码行都不合并。
- 缺失字段不当成零。导入批次同一编码有冲突价格时暂停整批确认。

`algorithm-version.json` 记录核心函数内容的 SHA-256。`public/core.js` 从 `const normalize` 起与本地运行版完全一致，仅将包含真实资料的 `SEED` 置为空数组。

## 数据接入和部署状态

本次仅保存网页源码，没有接入天猫或聚水潭实时后台，没有实现服务器商品资料目录监听，也没有执行云端部署。后续接入服务器资料时应复用现有核心函数，资料放在 Git 忽略的数据目录或服务端存储中。

本目录不包含尚未交付的浏览器 SKU 读取扩展。
