The packaged JSON mechanically retains numeric category ID, parent ID, name and
parent flag. The runtime is generated from our local resolver and that JSON.
No upstream executable code is used. No request to this repository or any
third-party query service is made during collection.

This is an attributed public historical factual reference, not a current official
Taobao/Tmall category list, an official affiliation, or a verified 2026 snapshot.
No explicit upstream license was found; this notice does not grant upstream rights
or make a licensing claim. Review data provenance and usage before redistribution.

Names and hierarchies may have changed since the source date. Page-provided current
names take precedence. Dictionary-filled values visibly carry their reference date.
Missing IDs, conflicting IDs/names and incomplete chains must not be guessed from
product titles or replaced with an unrelated category.
