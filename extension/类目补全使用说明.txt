淘啊竞品采集器 · 类目菜单误抓修补 1007-CAT2

本次修复
上一包会把“更多数据商品标题链接 SKU 属性 商品数据”误认为类目，并挡住本地表补全。
本包同时修复菜单容器读取和补全入口的错误值处理；无可靠 ID 时宁可不显示，也不猜测。
请使用文件名末尾为 1007-CAT2.zip 的新包，不要重复安装旧 1007.zip。
原工作台已保存的错误快照不会自动修改，必须刷新商品页后重新采集。

这次改了什么
读取当前商品页的真实类目 ID，自动在插件自带的类目表中查找名称及父级路径。
无需注册服务、填查询密钥或先点店透视。其他采集功能、上架时间、权限、版本号不变。
页面已经提供明确类目时，优先使用页面结果。

如何安装（不卸载）
1. 等当前采集和 AI 任务结束，保存需要的结果。备份原插件目录。
2. 解压 Taoa-Competitor-Collector-1.3.8-category-fix-1007-CAT2.zip。
3. 在浏览器“扩展管理 → 淘啊竞品采集器 → 详情”中查看加载来源。
4. 把压缩包里 Taoa-Competitor-Collector-1.3.8 文件夹内的全部内容覆盖到那个原加载目录。
   注意：manifest.json 和新增 category-runtime.js 要在原加载目录最外层，不能多套一层文件夹。
   不要卸载扩展，不要删除原目录，不要清空存储。
5. 在扩展管理中点击该扩展的“重新加载”（圆形箭头）。
6. 刷新已打开的商品页和竞品工作台，再点“采集已打开的商品页”。
   已经保存在工作台的旧记录不会自动变更，需要重新采集。

更新识别
原目录应出现 category-runtime.js，且本说明第一行包含“1007-CAT2”，版本号仍为 1.3.8。

如何看结果
如页面只给出类目 ID 50002798，本地表会补为：
餐饮具 > 餐具 > 碗（本地表参考·2020-07-27）

表中还包含文具、母婴、服饰、数码等，不局限于餐饮具。
按数字 ID 精确连接父子关系，不能因为商品名含“碗”就判为餐饮具。
如果本地表没有这个 ID，会显示该 ID 和“名称待补全”，不会编造名称。
若连可靠 ID 都没有读取到、商品归属不符或字段有冲突，保留原结果，不冒充采集成功。
