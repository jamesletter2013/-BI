# 多套个人 API · 无页面运行（扩展 V1.3.1）

工作台默认选个人 API，未配置时引导设置，不静默保存为“已发送”，不调用公司服务。未配置者可以显式选择手动草稿，继续复制、导出、粘贴 AI 回复。

## 安装与使用

1. 下载工作台设置中的 V1.3.1 ZIP 并解压。已有旧版请先等当前任务结束、复制结果，再备份原扩展目录，覆盖新版文件并点重新加载，以保留同一个扩展 ID 和采集存储；不要删除旧扩展或清空浏览器数据。首次安装在 Chrome 扩展管理页开启开发者模式、加载已解压的扩展。
2. 刷新工作台，点击对话输入框旁的设置按钮。只在打开的插件设置页填写 API Key。
3. 点击“新增 API”，分别为每套配置命名，选择接口格式，输入 HTTPS 基础地址/完整地址、模型 ID、API Key，点击“授权域名并保存”。可保存最多 100 套，包括同一家不同账户或模型。Chrome 只请求本次配置域名的权限；不会一次申请访问所有网站。
4. 返回工作台后自动读取无密钥的配置列表。在输入框下方选择本次使用的具名 API。推送资料、输入问题、回车或点发送。每套 API **首次发送**在当前对话框核对接收域名、模型、输出上限和费用并确认；授权记在本机插件内，后续仅在你主动发送时直接调用并计费。插件内部 Worker 执行，不新开分析标签页，成功后左侧自动生成建议。
5. 可关闭、刷新工作台或切换商品，已提交的个人请求继续等待。重新打开工作台，点击分析对话顶部「后台任务」，选择相应商品，取回当时快照与建议；这一步仅查看，不重新调用。最近 10 个任务保留在当前浏览器会话，取回将替换当前草稿，不改上方商品采集数据。
6. 保持 Chrome 运行且电脑不休眠。退出浏览器、禁用、重载或更新扩展会清除会话任务与密钥；退出前复制结果。执行器中断、超时、失败均不自动重发。主动点击停止按钮会停止本地等待，但无法保证服务商撤销已发请求，仍可能计费。

这次只改变个人 API 执行。公司模式仍由当前网页等待服务器回复；商品、评价、问大家采集仍依赖商品页，未改成无网页采集。

测试连接需明确点击并确认，发送一次简短测试，可能计费，不发送商品数据。保存配置、读取状态不调用模型。

“已保存的 API”下拉可切换编辑；清除本套密钥、删除本套 API 都不影响其他配置。旧版单套设置自动迁移为“原有 API”。扩展重载会使会话密钥失效，升级后需要重填，但地址、模型和本机授权保留。删除已选配置或调用失败不会自动换账户；执行中的配置不可修改。切换到未授权 API 时首次发送需确认，切回已授权且配置未变的 API 不重复确认。

授权绑定配置 ID、实际接收地址、接口格式、模型、DeepSeek 分析模式和输出上限；仅改名或保留相同配置重填会话密钥不会重置。修改绑定字段或清除本套密钥后需再次确认。可在插件「更多设置」撤销本套发送授权；网页不能修改配置或撤销授权。旧 V1.3.0 仍可发送，但每次确认，需升级后才会记住授权。

## 配置错误与输出上限

DeepSeek 官方 Flash 示例：格式为 Chat Completions，地址 `https://api.deepseek.com`，模型 ID **`deepseek-flash`**（包含连字符），不是 `deepseekflsh`。已知错误在调用前拦截并提示，不自动改模型。自定义服务商和其他模型仍按各自控制台填写。

HTTP 400 表示请求未被接受，需核对模型 ID、格式及资料长度。插件仅对有限大小的结构化错误做本地分类，不透传服务商原始文本。401/402/429 等分别提示密钥、余额、额度或频率问题。所有失败均不自动重试。

默认 4000 tokens 是插件发给接口的**单次输出上限**，不是模型的上下文容量、最大输出能力或账户余额。输出被截断时不覆盖已有建议，可在「更多设置」手动调整；重复请求仍可能计费。模型官方规格以[DeepSeek 文档](https://api-docs.deepseek.com/quick_start/pricing/)为准。

DeepSeek 官方 Chat Completions 提供「普通分析 / 深度思考」。新版默认普通分析（包含未设置此字段的旧配置），明确发送 `thinking: {type: 'disabled'}`，避免默认进入思考模式；选深度思考则发送 `enabled`，但不会自动提高输出上限。思考内容可能占用输出预算，截断时如返回用量则显示数字，不展示思维链。其他服务商沿用原协议，不注入 DeepSeek 专有参数。测试连接始终使用普通模式、256 tokens，不修改已保存的模式，仍需用户单独确认一次收费测试。

## 长文字编辑

输入框右上角“展开编辑”打开大窗口，与原输入框共享同一份文字；收起、Esc 或点遮罩不会清空。Enter 发送，Shift+Enter 换行，中文输入法选字不会误发。最多 6000 字符，页面模块保持固定尺寸。草稿仍只在当前页面暂存，刷新前请复制。

## 支持范围

| 格式 | 地址示例 | 鉴权 |
| --- | --- | --- |
| Chat Completions（OpenAI 兼容） | `https://api.deepseek.com`、`https://api.openai.com/v1` 或以 `/chat/completions` 结尾的完整地址 | Bearer API Key |
| Claude Messages | `https://api.anthropic.com/v1` 或以 `/messages` 结尾的完整地址 | x-api-key |
| Gemini generateContent | `https://generativelanguage.googleapis.com/v1beta` | x-goog-api-key |

用户可填写符合相应格式的其他官方/中转服务地址和模型，不绑定公司名称。**不是任何协议通用**：不支持 Responses、Azure 专用鉴权、HMAC 签名、OAuth、非 HTTPS、本机地址，或要求额外请求参数的专有接口。当前只做文字分析，不请求图像、不接入工具调用。模型应能按提示输出 3–5 条建议 JSON；不完整、超限或商品不匹配时保留原建议。输出上限可自行调节 256–16000 tokens；模型实际能力/价格由服务商决定。

不要将不兼容接口误称“已接入”。用户自己的模型额度由其服务商扣费，本工具不代收；服务商收费、可用性及隐私政策由用户核对。

## 密钥与数据边界

- 密钥仅在插件的 `chrome.storage.session`（TRUSTED_CONTEXTS）内保存。浏览器重启、禁用、重载或更新扩展后需重新填写。密钥不持久写盘、不进入 sync、页面 localStorage、工作台消息、服务端、日志或导出包；非密钥配置留在插件本机 local 存储。
- 更换接收域名必须重新填写密钥，不能自动将旧密钥迁移到新域名。只允许 HTTPS 公网域名、不允许 URL 携带查询参数或凭证。浏览器请求不带 Cookie、不自动跟随重定向。错误不透传接口原始响应体。
- 个人调用在扩展内部 offscreen 文档的独立 Worker 中执行，与图片打包共用唯一 offscreen 文档，使用实际 WORKERS/BLOBS 用途，不假装播放音频保活。首次在工作台内确认，由插件检查绑定授权并持久记在本机；网页没有任意 URL 代理、密钥读取、设置写入入口。
- 网站与插件只在固定工作台域名的顶层页面通信；后台检查扩展 ID、sender URL、tab、frame。任务先保存并登记随机请求 ID，内部执行器只可领取一次；配置 ID、版本和商品绑定本次快照，不自动换账户。即时消息发往原文档，固定工作台可从当前浏览器会话重新读取已有任务，不再次收费。密钥只通过验证过的内部请求回应交给 Worker，不写入任务记录、广播或回传网页。
- 个人模式不会请求 `/api/ai/analyze`；公司模式需要独立服务端员工名单，不能靠切换前端选项获得权限。公司名单默认留空。现在网站仍保持原有私有访问范围；尚未上架扩展商店或公开站点。

接口兼容性采用离线模拟测试，不等于每家服务商都已真实联调。`work/test-background-ai.mjs` 覆盖无新标签、首次/后续发送、领取去重、后台线程重建、关闭工作台、取回结果、主动取消、晚到回复、权限撤销、超时和中断；`work/test-consent-ai.mjs` 覆盖授权隔离、重启保留、配置变更失效、撤销、存储失败及错误脱敏分类。发布验收不使用真实密钥或消耗收费额度；用户可自行点击测试连接。本轮尚未在真实 Chrome 中完成带密钥的端到端联调。
