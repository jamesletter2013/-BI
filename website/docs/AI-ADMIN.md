# 管理员接入 AI

此版内置 DeepSeek 官方适配器，后续服务商共用 `/api/ai/status` 与 `/api/ai/analyze`，不改变采集插件和资料推送流程。

## 启用步骤

1. 在当前 Sites 项目的**生产运行环境**配置 `DEEPSEEK_API_KEY`，标记为 secret。不要把密钥发在聊天里、提交 GitHub、放进浏览器插件或以 `VITE_` / `NEXT_PUBLIC_` 开头。
2. 确认 DeepSeek 账户额度与公司使用规则后，设置 `AI_ENABLED=true`。默认未设置 / false 均不调用。
3. 设置 `AI_DAILY_USER_LIMIT`（默认 20，最高 200）和 `AI_DAILY_TEAM_LIMIT`（默认 100，最高 1000），重新部署使配置生效。这是北京时间每天的**尝试次数**，不是金额预算。
4. 当前站点保持仅所有者可访问。小范围联调成功后，再通过 Sites 访问名单邀请同事。不要直接切为公开。
5. 确认页面显示 API 已启用，在知悉按量计费后手动发送一份小资料做真实联调；配置检测本身不调用 DeepSeek，也不能证明密钥有效。

员工不填写密钥：采集 → 推送快照（默认差评）→ 选择服务商/模型 → 勾选发送与使用额度 → 发送并生成建议。原来的复制 / TXT 导出 / 粘贴 AI 回复继续保留。

## 发送状态与排查

确认发送后，问题立即进入上方对话，输入框清空；同一次请求返回「检查资料与额度 → 等待 DeepSeek 回复 → 整理建议」阶段和已等待时间，不使用虚假百分比。有效结果自动生成左侧建议卡片。失败直接显示在对话中，可重新编辑问题，但不会自动重试；已有建议不会被清空。

前端通过 `Accept: application/x-ndjson` 接收进度，原 JSON 客户端仍可使用。进度不额外调用模型、不额外扣次数；流中断或取消不代表服务商一定未计费。对话中的短请求编号可关联服务端脱敏日志和数据库完整请求 ID。

2026-10-04 修复：当前 Worker 运行时不支持 `fetch` 的 `redirect: 'error'`，会在请求发出前抛错。适配器改用 `manual` 并拒绝所有 3xx，避免授权头被转发。仅检查「API 已启用」不能证明密钥或账户余额有效；管理员仍需在许可次数内做一次真实小资料联调。历史失败次数未重置。

## 调用与费用保护

- 只有明确点击发送才调用；采集、打开页面、切换模型、推送资料不会调用。
- 单次资料与对话最多 60,000 字符、请求体最多 240,000 字节，最多 4,000 输出 tokens；超限明确拒绝，不静默删掉评价。关闭 thinking，采用普通文字分析。
- 最近 12 条对话参与追问；更新快照开始新一轮。并发与快速重复提交受限制，服务端对请求 ID 幂等拒绝。
- 每人和团队的每日计数使用数据库原子预留，失败尝试也计数；拒绝自动重试，取消 / 超时不保证服务商未扣费。
- 返回必须是当前商品的 3–5 条建议，包含标题、优先级、依据、行动与验证方式；格式错误、超时、断连不覆盖原建议。
- 本版只分析文字，图片/视频仅作为链接，不发起图像读取，不宣称做过视觉分析。后续接入多模态时须另行明确图片范围和费用。

## 数据与认证边界

使用 Sites 分发层提供的已认证用户标识，并检查同源 JSON 请求。数据库仅记录随机请求 ID、用户 ID 的 SHA-256 摘要、日期、状态、模型及 token 数；不保存提示词、评价正文、AI 回复或密钥。浏览器草稿仍是本页临时数据，刷新前应导出。

**不要把本项目直接部署到一个信任用户自填 `oai-authenticated-user-*` 请求头的普通服务器。** 改用其他托管平台时，必须先替换为该平台的服务端会话认证、团队访问控制和数据库实现；未经认证不要启用 `AI_ENABLED`。

## 扩展服务商

在 `lib/ai/providers.ts` 实现 `AIProvider`：固定官方 URL、服务端 secret 读取、模型白名单、响应归一化与错误脱敏，然后注册到 `providers`。前端自动显示注册模型，不接受员工提交 Base URL、API Key 或系统提示词。不同协议使用单独适配器，不能仅通过改域名假定兼容。

当前模型配置按 2026-10-04 的官方文档核对：`deepseek-flash` 和 `deepseek-v4-pro`。模型与价格可能调整，启用前可核对 [官方模型列表](https://api-docs.deepseek.com/quick_start/pricing/) 和 [Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)。本仓库不承诺固定 API 价格。

## 本地与数据库

`.env.example` 只包含空密钥和默认禁用开关。生产密钥只在 Sites secret 中设置；本地 Worker 使用被 Git 忽略的 `.dev.vars`，不要启用公网本地预览或伪造生产身份。数据库迁移位于 `drizzle/`，通过 Sites 发布应用；不得在运行时创建表。使用模拟适配器测试，不需要真实 API key。

本次验收：离线验证认证、同源、禁用/无密钥拒绝、模型白名单、资料长度、重复请求、原子每日次数、不完整回复、进度流、断连/失败脱敏和建议解析；本地模拟验收即时问题气泡、等待计时、成功回填、失败保留与重新编辑。无密钥模型列表请求确认 Worker 可连接官方接口；未进行收费 API 联调。
